# 🩺 Multi-Disease Prediction System using Machine Learning & Streamlit
A smart and interactive web application that predicts the likelihood of Diabetes, Kidney Disease, and Heart Disease using Machine Learning models.
This system analyzes user-provided medical parameters and generates real-time disease predictions, helping users with early detection, awareness, and better health decisions.

# 🚀 Features
✅ Multi-Disease Prediction
     Predicts the likelihood of:
       1. Diabetes
       2. Kidney Disease
       3. Heart Disease

✅ Clean & Interactive UI
    Built using Streamlit with:
     1. Sidebar menu
     2. User-friendly form inputs
     3.Images, expanders & 3-column layout

✅ Trained ML Models
   Each disease has its own trained model using algorithms like:
    1. Logistic Regression
    2. Random Forest
    3. Decision Tree
    4. Support Vector Machine (SVM)
    5. XG Boost Classifier

✅ Data Preprocessing
  1. Scaling
  2. Handling missing values
  3. Feature selectionwith graph plots
